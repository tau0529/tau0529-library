# tau0529-library

競技プログラミング用の自作C++ライブラリです。

AtCoderなどのプログラミングコンテストで使用することを目的として、アルゴリズム・データ構造・便利関数などをまとめています。

## 特徴

- **C++20** に対応
- AtCoder Library（ACL）を利用可能な環境では自動で読み込み
- STLコンテナの入出力や演算を拡張
- 数学関数、データ構造、多倍長整数などを実装
- 個別のライブラリから、提出用の単一ファイルを自動生成

## ファイル構成

| ファイル | 内容 |
|---|---|
| `base.hpp` | 標準ライブラリ・ACLの読み込み |
| `io.hpp` | vector・pair・STLコンテナなどの入出力 |
| `operators.hpp` | vector・pairなどの演算子 |
| `utilities.hpp` | 型エイリアス・マクロ・定数・便利関数 |
| `seg_tree.hpp` | セグメント木・遅延セグメント木 |
| `math.hpp` | 数学関数・組合せ・素数・数論 |
| `bigint.hpp` | 多倍長整数 |
| `data_structures.hpp` | その他のデータ構造 |
| `build.py` | ライブラリの自動結合 |
| `template.cpp` | 提出用の統合テンプレート |

## 使い方

### テンプレートの生成

リポジトリのディレクトリで以下を実行します。

```bash
python3 build.py
```

各ライブラリが結合され、`template.cpp` が生成されます。

### コンパイル

```bash
g++ -std=c++20 -O2 template.cpp -o main
```

`template.cpp` は、競技プログラミングの提出時に単一ファイルとして利用することを想定しています。

## 注意事項

- 個人利用を主な目的として開発しています。
- 一部の機能はAtCoder Library（ACL）に依存します。
- 開発途中のため、仕様や実装が変更される場合があります。
